Small teams end up paying for a tracker, a support inbox, a roadmap tool and a
feedback board, then spend their time copying context between them. Forge is the
argument that for a team my size those are all views over the same data, and the
copying is the actual cost.

## What's in it

Work lives as issues with linking, exploration and time tracking, and projects
render that same work as a board, a calendar, a timeline or a roadmap depending
on the question being asked. Around that sit a support desk with ticket intake
and triage, feedback boards with voting and moderation, and role-aware dashboards
that show a given person their own slice. GitHub webhooks pull repository
activity in so commits and issues sit beside the planning rather than in another
tab.

## Built with

Laravel 12 on PHP 8.3, Livewire 3 and Jetstream for the interactive surfaces,
Filament 4 for the admin panel, and Bootstrap 5 alongside Tailwind CSS 4 built
through Vite. AGPL-3.0.

This is the largest thing I've built on my own — comfortably past eighteen
hundred commits — and it's still in active development.
